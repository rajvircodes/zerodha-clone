# 🚀 Zerodha Clone

A full-stack stock trading dashboard inspired by Zerodha, built using the MERN stack. This project demonstrates modern web development concepts including authentication, CRUD operations, protected routes, API integration, dashboard architecture, and deployment.

## 📌 Project Overview

This project consists of three separate applications:

### Frontend Website

A marketing website inspired by Zerodha containing:

* Home Page
* Products Page
* Pricing Page
* About Page
* Support Page

### Trading Dashboard

A dedicated dashboard where users can:

* Register Account
* Login Securely
* View Holdings
* Manage Orders
* Track Positions
* View Funds
* Access Protected Routes

### Backend API

A Node.js + Express backend that handles:

* Authentication
* JWT Authorization
* Database Operations
* CRUD APIs
* User Management

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/rajvircodes/zerodha-clone.git
```

### Install Dependencies

Frontend

```bash
cd frontend
npm install
```

Dashboard

```bash
cd dashboard
npm install
```

Backend

```bash
cd backend
npm install
```

---

## ▶️ Run Locally

Backend

Frontend

Dashboard
